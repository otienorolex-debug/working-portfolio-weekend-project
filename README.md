# Rolex Otieno — Personal Portfolio

A responsive, single-page portfolio introducing Rolex Otieno, his skills, projects, and contact details.

## Live demo

[Open the live portfolio](https://otienorolex-debug.github.io/Weekend_portfolio/weekend_assignment/)

## Features

- About section with a short introduction and profile image.
- Skills displayed from a JavaScript array.
- Project cards created from a JavaScript array of project objects.
- Contact cards for email, phone, and GitHub, generated with JavaScript.
- Responsive layout with a dark theme and green accent color.

## Technologies used

- HTML
- CSS
- JavaScript

## Run locally

1. Download or clone the repository.
2. Open `index.html` in a web browser.

## What I learned

I learned how to structure a single-page portfolio with HTML and style it for different screen sizes using CSS. I also practiced storing skills and project information in JavaScript arrays and using loops to display that information on the page.
